## 二、支付模块变更

### 2.1 支付成功后视频状态（⭐重要）

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| 后端状态更新 | 后端更新视频状态为 **【下载中】** | 后端更新视频状态为 **【待下载】** |
| 视频封面 | 视频封面变为【下载中】状态，并排到视频回放列表**最前位置** | 视频封面变为 **【待下载】** 状态 |
| 我的视频入口 | 【我的视频】页面新增下载中视频 | **【我的视频-制作中】** 页面新增该视频 |

> 💡 分析：区分了"支付完成待下载"和"正在下载中"两个状态，语义更精确，与后续"制作中"视频列表页逻辑一致。

### 2.2 视频退款逻辑（⭐⭐重大变更）

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| 失败状态描述 | 统一为【制作失败】 | 细分为 **【下载失败】** 和 **【制作失败】** 两种状态 |
| 安卓退款前提 | 未明确 | 明确 **"此处指我方原因导致"**（文件出错、本地制作出错且自动重试3次无效） |
| 安卓退款按钮显示 | 未明确 | **比赛记录、我的视频** 两个页面均显示【退款】按钮 |
| 安卓自动退款条件 | 退款且视频无url时 | 保持不变，但描述更清晰 |
| **iOS退款时间窗口** | 解锁后 **48h** 内不退款 / 48h后判断 | 解锁后 **72h** 内不退款 / 72h后判断 |
| iOS - 工控机制作视频 | 统一规则 | 72h后：**无url → 退款**；**有url → 不退款** |
| iOS - App本地制作视频 | **无此逻辑** | **新增**：已下载失败/制作失败 → **退款**；其余状态 → **不退款** |
| 后台状态 | 简单提及 | **新增**"后台订单记录-退款状态刷新" |

> 💡 分析：关键变化是 iOS 退款判断时间从 48h → **72h**，且针对本地制作视频新增了一套独立的退款判断逻辑。

### 2.3 视频价格分类（⭐）

| 旧版 | 变更版 |
|------|--------|
| **失误集锦**单独一组（≤5/1元，≤15/3元，>15/5元） | **精彩集锦、失误集锦** 合并为一组（≤5/1元，≤15/3元，>15/5元） |
| 精彩集锦、单杆视频、局视频一组 | 单杆视频、局视频一组 |

### 2.4 购买视频券（⭐）

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| 入口描述 | "**我的页面** → 视频券购买入口 → 视频券落地页" | "**我的 → 视频券购买banner** → 视频券落地页"（更具体） |
| 支付成功后更新 | 视频券数量刷新 + 【我的卡券】新增记录 | **新增**：比赛记录页面底部视频券数量也要更新 |

### 2.5 后台状态变更（⭐）

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| 描述用词 | "购买的**记录**" | "购买的**状态**" |
| 购买渠道字段 | "增加【购买渠道】字段" | **【购买渠道】字段：新增【App】** |
| 筛选项 | "增加【购买渠道】筛选项" | **【购买渠道】筛选项：新增【App】** |
| 套餐明细额外字段 | 无 | **新增**：【购买平台】、【退款状态】字段需正确更新 |

### 2.6 支付失败异常处理（🆕新增讨论项）

变更版新增了一段 **待讨论** 内容：

> "用户在前端付款成功，但因通讯/网络原因后端状态未更新，按支付失败处理，需原路退款，后端状态在通讯/网络恢复后更新正确的订单状态，并确保不要重复退款等"

## 三、个人数据可视化变更

### 3.1 首页个人卡片（⭐⭐）

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| "我的视频"数据定义 | "已解锁视频数量（不含下载中、制作中视频）" | **大幅扩展**：数量 = 所有已解锁视频数量（包括App、工控机制作的，腾讯云有链接的视频数；腾讯云已删除的不计入） |
| 待确认项 | 无 | **新增**："已解锁视频数量 / 本地视频数量？" |
| New角标 | 无 | **新增**：有新的制作完成视频时，【我的视频】角标提示数量 |
| 角标数量逻辑 | 无 | 角标数量 = 已制作完成未查看的视频数量；每点击播放一个new视频，角标数量 -1 |
| 旧提示条 | 未提及 | **新增**：原首页新视频未查看的提示条 **去除** |
| 我的视频页面 | 无 | **新增**：我的视频页面增加 new 标志 |

### 3.2 个人数据页面优化（⭐⭐）

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| 点击自己头像 | "取消跳转" | "**无效**"（更明确） |
| 点击他人头像 | "仍进入原页面" | "仍进入 **个人数据** 页面"（明确去向） |
| 时间筛选-近三月 | 无标注 | **新增"（待确认）"** |
| 时间筛选切换 | 未提及 | **新增**：交手记录/我的数据切换时，时间筛选项 **不重置** |
| 总局数等计算 | "根据时间筛选变化" | **改为**："计算所选时间内，平均每局的数据（现有逻辑）" |
| 评级卡片标题 | "我的评级卡片" | "**当前评级卡片**" |
| 评级卡片内容 | "展示用户当前评级及能力图谱" | **新增"称号"**：显示用户当前评级、**称号**及能力图谱 |
| 进球率数据展示 | 仅进球率 | **新增**：以下数据分别显示 **平均与最佳** 数据（红球/彩球/长台/走位/架杆成功率） |
| 走位/架杆成功率 | 仅"新增" | **新增**：支持根据时间范围计算 |
| 数据保留规则 | 未提及 | **新增**：所有数据 **仅保留整数部分**（小数大于5也舍弃） |
| 折线图说明 | 简要 | **大幅扩展**：一页最多6个数据点、横滑查看、无数据节点处理、单数据点处理等详细规则 |
| 查询速度要求 | "页面 **数据返回** 时间 < **1s**" | "页面 **加载+数据查询** 时间 < **3s**" |
| 待确认年份 | "是否可以只查看近**一年**的数据？" | "是否可以只查看近**三年**的数据？（小程序？？）" |
| UI颜色区分 | 做 | **"（不做）"** |
| 页面空状态 | 未提及 | **新增**：卡片、页面空状态均以UI图为准 |

## 六、全新增加的需求点（变更版独有）

### 6.1 "一期遗留优化需求及新增需求"整章

**优化项：**

| 编号 | 内容 |
|------|------|
| 1 | 每次重装app/换手机/缓存清除，视频卡片状态改为"本地文件被删除"（而非制作中断） |
| 2 | app制作视频清晰度待讨论优化 |
| 3 | app制作的视频俱乐部名称模糊，需优化显示 |
| 4 | 页面字体大小自适应优化（全局自适应 + 固定字号兜底） |
| 5 | 无头像用户由后端赋默认头像，计分系统端同步显示 |
| 6 | 排行榜头像加载慢/失败（待验证待优化） |
| 7 | 华为安装包压缩（32位+64位兼容包 360MB+，需压缩） |
| 8 | 视频崩溃问题 |

**新增需求项：**

| 编号 | 内容 |
|------|------|
| 1 | 工控机制作的视频支持倍速（改成预览态） |
| 2 | 下载视频体验优化：退出播放器仍有下载进度显示 |
| 3 | 比赛记录/排行榜点击已注销用户头像 → 弹toast"该用户已注销"（原为空页面） |
| 4 | 视频卡片不同状态底图替换（以UI图为准） |
| 5 | UI页面优化补充 |

### 6.2 机型适配变更

| 维度 | 旧版 | 变更版 |
|------|------|--------|
| 安卓最低版本 | 安卓 10.0 | **安卓 8.0** |
| iOS最低版本 | iOS 15 | **iOS 14**（iPhone11） |
