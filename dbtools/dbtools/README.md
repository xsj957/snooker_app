# DB Query Tool — supervisions 数据库实时查询

> 带 HTML 界面的 MySQL 只读查询工具，专为测试工程师日常排查设计。

## 启动

```bash
# 默认启动（localhost:8900）
python dbtools/server.py

# 指定端口
python dbtools/server.py --port 9000
```

启动后浏览器打开 `http://localhost:8900`

## 功能

| 功能 | 说明 |
|------|------|
| SQL 编辑器 | 支持 Ctrl+Enter 执行，Ctrl+L 清空 |
| 结果表格 | 表头固定，可横向滚动，点击单元格复制 |
| 列排序 | 点击表头按该列排序 |
| 数据表列表 | 左侧栏显示所有表，点击查看表结构 |
| 常用查询模板 | 按模块分类的预置 SQL，点击填入编辑器 |
| 查询历史 | 最近 20 条查询记录，点击回填 |
| CSV 导出 | 一键导出查询结果为 CSV 文件 |
| 测试用户快捷复制 | 底部快捷按钮复制测试用户 ID |

## 安全限制

- **只读模式**：仅支持 `SELECT` / `SHOW` / `DESCRIBE` / `EXPLAIN`
- **禁止写入**：`INSERT` / `UPDATE` / `DELETE` / `DROP` / `ALTER` 等全部禁止
- **禁止多语句**：一次只能执行一条 SQL
- **自动 LIMIT**：未指定 LIMIT 的 SELECT 自动追加 `LIMIT 1000`
- **仅限 supervisions 库**

## 常用查询模板分类

- **用户查询**：基本信息、授权登录、扩展信息、资产余额
- **视频券**：券列表、有效数量、即将过期、使用追溯、按 ID 查询
- **视频订单**：全部订单、现金解锁、券解锁、App 端记录、重复检测
- **套餐订单**：用户套餐、套餐定义、已过期套餐
- **视频制作状态**：制作状态查询、各状态统计、下载/制作失败、按设备查
- **视频目录**：视频详情、分类统计、原片地址
- **退款**：退款记录、退款失败、待审核
- **数据统计**：全量概览、渠道分布、每日趋势、播放排行、定价规则
- **问题排查**：已支付无原片、状态不一致、有券未用、券未到账、超 48h 未解锁
