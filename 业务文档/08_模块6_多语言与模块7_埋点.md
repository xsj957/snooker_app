## 模块6：多语言支持

### 6.1 语言支持范围

#### 6.1.1 国内版

**支持语言**:
- 中文（默认）
- 英文

**语言切换**:
- 跟随系统语言设置
- 如系统语言为中文，App显示中文
- 如系统语言为英文或其他语言，App显示英文

#### 6.1.2 海外版

**支持语言**:
- 多语言（具体语言列表待确认）

**语言切换**:
- 跟随系统语言设置
- 支持的语言显示对应语言
- 不支持的语言显示英文（默认）

---

### 6.2 文案管理

#### 6.2.1 中文文案

**补充范围**:
- 第一期所有新增功能的中文文案
- 包括但不限于：
  - 登录页文案
  - 视频制作状态文案
  - 播放器文案
  - 提示文案
  - 错误提示文案

**文案规范**:
- 简洁明了
- 符合用户习惯
- 与小程序文案保持一致（如适用）

#### 6.2.2 英文文案

**补充范围**:
- 第一期所有新增功能的英文文案
- 已与Figma设计稿评论中提供

**文案规范**:
- 符合英文习惯
- 简洁明了
- 与中文文案含义一致

**英文文案示例**:
- 存储空间不足："Insufficient storage space on your device."
- 制作中："Producing, please check in App"
- 制作失败："Production failed, please check in App"
- 制作成功："Production successful, please check in App"
- 已过期："Expired"

---

### 6.3 多语言适配要求

#### 6.3.1 UI适配

**文字长度适配**:
- 英文文案通常比中文长
- UI设计需考虑文字长度变化
- 按钮、标签等元素需支持文字自适应

**布局适配**:
- 避免因文字过长导致布局错乱
- 使用弹性布局
- 必要时调整字号

#### 6.3.2 日期时间格式

**日期格式**:
- 中文：2026年8月5日
- 英文：Aug 5, 2026

**时间格式**:
- 中文：14:30
- 英文：2:30 PM

#### 6.3.3 数字格式

**数字分隔符**:
- 中文：1,000,000
- 英文：1,000,000

**货币格式**:
- 中文：¥9.9
- 英文：$9.9

## 模块7：埋点规范

### 7.1 埋点事件清单（11个新增事件）

第一期新增11个埋点事件，用于追踪用户行为和转化漏斗。

#### 7.1.1 用户相关事件

**user_signup（用户注册）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 安装后首次启动并完成登录/token获取 |
| 上报属性 | signup_channel: wechat |
| 对应指标 | App激活率 |

**user_login（用户登录）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 用户每次登录成功时上报（除首次外） |
| 上报属性 | login_method: wechat<br>品牌、厂商、机型、系统版本 |
| 对应指标 | App登录次数 |

#### 7.1.2 视频卡片点击事件

**player_videocard（点击交手卡片-视频卡片）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 点击交手卡片下的视频卡片 |
| 上报属性 | playervideo_click |
| 对应指标 | 曝光点击率 |

**match_videocard（点击场卡片-视频卡片）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 点击场卡片下的视频卡片 |
| 上报属性 | matchvideo_click |
| 对应指标 | 曝光点击率 |

#### 7.1.3 视频解锁事件

**video_unlock_start（解锁视频成功）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 解锁视频成功时上报（券/现金） |
| 上报属性 | unlock_type: 0=用活动券解锁, 1=用套餐券解锁, 2=付费解锁<br>video_price: 上报视频付费金额<br>video_type: 1=单杆视频, 2=精彩集锦, 3=失误集锦, 4=局视频<br>video_id: 视频ID |
| 对应指标 | 视频解锁率 |

**video_unlock_success（解锁成功、进入下载）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 解锁成功、进入下载时上报 |
| 上报属性 | unlock_type, video_type, video_id |
| 对应指标 | 视频解锁率 |

#### 7.1.4 原片下载事件

**origin_download_success（原片下载成功）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 原片下载成功时上报 |
| 上报属性 | video_type, video_id |
| 对应指标 | 下载转化 |

**origin_download_fail（原片下载失败）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 原片下载失败时上报 |
| 上报属性 | video_type, video_id<br>fail_reason: 1=网络异常, 2=云端文件丢失, 3=用户杀掉app |
| 对应指标 | 下载转化 |

#### 7.1.5 本地制作事件

**local_make_start（本地制作开始）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 本地制作开始时上报 |
| 上报属性 | video_type, video_id<br>device_info: 设备机型<br>make_duration: 制作时长 |
| 对应指标 | 视频制作效率与各机型制作情况 |

**local_make_success（本地制作成功）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 本地制作成功时上报 |
| 上报属性 | video_type, video_id<br>device_info, make_duration |
| 对应指标 | 视频制作效率 |

**local_make_fail（本地制作失败）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 本地制作失败时上报 |
| 上报属性 | video_type, video_id<br>device_info, make_duration<br>fail_reason: 1=音频合成失败, 2=本地下载文件不存在, 3=用户杀掉app |
| 对应指标 | 视频制作效率 |

#### 7.1.6 视频播放事件

**video_play（成品视频播放）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 成品视频播放，每开始播放一次上报一次 |
| 上报属性 | video_type, video_id |
| 对应指标 | 视频使用率 |

#### 7.1.7 视频分享事件

**video_share（分享动作完成）**

| 属性 | 说明 |
|------|------|
| 触发时机 | 分享动作完成 |
| 上报属性 | channel: 1=微信好友, 2=朋友圈, 3=抖音, 4=相册<br>video_type, video_id |
| 对应指标 | 视频分享率 |

---

### 7.2 事件上报字段说明

#### 7.2.1 通用字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| video_type | 视频类型 | 1=单杆视频, 2=精彩集锦, 3=失误集锦, 4=局视频 |
| video_id | 视频ID | 视频唯一标识 |
| device_info | 设备机型 | iPhone 13, Huawei P50 |
| make_duration | 制作时长 | 180（秒） |

#### 7.2.2 特殊字段

**unlock_type（解锁类型）**:
- 0: 用活动券解锁
- 1: 用套餐券解锁
- 2: 付费解锁

**fail_reason（失败原因）**:
- 下载失败:
  - 1: 网络异常
  - 2: 云端文件丢失
  - 3: 用户杀掉app
- 制作失败:
  - 1: 音频合成失败
  - 2: 本地下载文件不存在
  - 3: 用户杀掉app

**channel（分享渠道）**:
- 1: 微信好友
- 2: 朋友圈
- 3: 抖音
- 4: 相册

---

### 7.3 埋点数据来源

#### 7.3.1 from_type标识

**视频事件来源**:
- from_type=1: 工控机
- from_type=2: 小程序
- from_type=3: App

**注意**: 第一期App端的埋点，from_type统一为3
