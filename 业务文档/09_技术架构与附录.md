# 技术架构要点与附录

## 一、技术架构要点

### 1.1 前后端技术栈

#### 1.1.1 客户端技术栈

**iOS端**:
- 开发语言：Swift / Objective-C
- 最低系统版本：iOS 14（iPhone 11）
- 适配机型：iPhone（小屏幕）、iPhone Pro Max（大屏幕）

**Android端**:
- 开发语言：Kotlin / Java
- 最低系统版本：安卓8.0
- 适配机型：华为（旧版鸿蒙：HarmonyOS 4.3及以前）、小米、OPPO、vivo

#### 1.1.2 后端技术栈

**服务器架构**:
- 国内版：国内服务器
- 海外版：海外服务器

**主要接口**:
- 微信登录接口：`/api/auth/wechat/login`
- 视频解锁接口
- 视频状态查询接口
- 用户数据同步接口

### 1.2 视频存储方案（腾讯云）

#### 1.2.1 存储架构

**存储服务**: 腾讯云视频点播（VOD）

**存储内容**:
- 视频原片（工控机裁切上传）
- 视频素材数据（比分、头像、时间戳等）
- 成品视频（App本地制作完成后上传）

**存储域名**: `vod2.myqcloud.com`

#### 1.2.2 视频下载

**下载流程**:
1. App从腾讯云下载原片
2. 下载视频素材数据
3. 缓存至App本地

**并发限制**:
- 同时最大下载数：2个
- 任务队列优先级：下载任务 > 制作任务

**下载检测**:
- 下载前检测手机剩余空间
- 下载过程中持续检测空间
- 空间不足时提示并终止下载

### 1.3 数据库核心表结构

#### 1.3.1 video_client_status（视频状态跟踪表）

**表说明**: 跟踪App视频的制作状态

**核心字段**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| video_id | INT | 视频ID |
| user_id | INT | 用户ID |
| status | TINYINT | 状态值（0-8） |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**状态值说明**:
- 0: 待解锁
- 1: 已解锁等待上传
- 2: 原片已上传
- 3: 下载中
- 4: 下载失败
- 5: 本地制作中
- 6: 制作失败
- 7: 制作完成
- 8: 已过期

#### 1.3.2 video_order（视频订单表）

**表说明**: 记录视频解锁订单

**核心字段**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| user_id | INT | 用户ID |
| video_id | INT | 视频ID |
| pay_channel | TINYINT | 支付渠道（0-3） |
| pay_amount | DECIMAL | 支付金额 |
| refund_status | TINYINT | 退款状态（0-3） |
| created_at | DATETIME | 创建时间 |

#### 1.3.3 video_source（视频原片表）

**表说明**: 存储视频原片地址

**核心字段**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| video_id | INT | 视频ID |
| url_video | VARCHAR | 视频URL（腾讯云） |
| created_at | DATETIME | 创建时间 |

#### 1.3.4 video_coupon_record（视频券记录表）

**表说明**: 记录用户视频券

**核心字段**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT | 主键 |
| user_id | INT | 用户ID |
| status | TINYINT | 状态（0=有效, 1=已使用, 2=已过期） |
| expire_at | DATETIME | 过期时间 |
| created_at | DATETIME | 创建时间 |
