## 三、App端流程（待开发，当前无数据）

当App开发完成后，视频生命周期将扩展为：

```
小程序解锁(video_order)
    │
    ▼
video_client_status: status=0 (待解锁)
    │  (用户在App内点击解锁)
    ▼
status=1 (已解锁等待上传)
    │  (App上传原片片段到腾讯云)
    ▼
status=2 (原片已上传)
    │  (App从腾讯云下载原片)
    ▼
status=3 (下载中) → status=4 (下载失败) [异常分支]
    │
    ▼
status=5 (本地制作中) → status=6 (制作失败) [异常分支]
    │
    ▼
status=7 (制作完成) → 视频存相册 + 本地缓存
    │
    ▼ (48h未操作 / 90d未制作)
status=8 (已过期)
```

**video_client_status 表结构**:
```sql
video_id      -- 关联 video_order.video_id
video_order_id -- 关联 video_order.id
client_id     -- 设备UDID
status        -- 0~8 状态值
created_at    -- 记录创建时间
updated_at    -- 最后状态变更时间（自动更新）
```

**App端播放**会在 video_event 表中新增 `from_type=3` 的记录。
